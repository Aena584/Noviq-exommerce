# Noviq E-Commerce Store 🛍️

Welcome to **Noviq E-Commerce Store**, an online shopping platform designed to provide customers with a simple, convenient, and user-friendly shopping experience.

## 📌 About the Project

Noviq is an e-commerce website that allows users to explore products, view product details, and shop through an organized online store interface. The project focuses on creating an attractive design and making online shopping easy for customers.

## ✨ Features

- **User-Friendly Interface:** Simple and easy-to-navigate design.
- **Product Listings:** Display products with images, names, and prices.
- **Product Details:** View information about available products.
- **Shopping Cart:** Add and manage products in the cart.
- **Responsive Design:** Designed to work across different screen sizes.
- **Easy Navigation:** Browse different sections of the store.
